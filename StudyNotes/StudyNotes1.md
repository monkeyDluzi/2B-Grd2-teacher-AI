print = Show text on the screen  example: print("Hello, World!")

variable = A named box that stores information

if = Check if something is true example: if x > 5:

elif = If the first check was false, check another thing (you could have many elifs) example: elif x < 5:

else = If none of the previous checks were true example: else: print("x is equal to 5")

def = Define (create) a function example: def my_function(): 

pass = Do nothing for now (placeholder) example: pass

to run a function = Call the function by writing its name followed by parentheses (e.g., my_function())
